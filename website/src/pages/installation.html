The latest release is always on the releases page. The latest release page always points at the current version.

The binaries are not code-signed. Windows SmartScreen will show an unfamiliar-app warning on first run, and the application has no publisher reputation. Verify the published SHA-256 checksum before choosing More info → Run anyway. Never disable antivirus or Windows security protections to install it.

Verify what you downloaded

Each release publishes a SHA256SUMS.txt. Compare it with your download:

Get-FileHash ".\LocalServerExposer_1.0.0_x64-setup.exe" -Algorithm SHA256

The published line looks like this — the hash must match exactly: 

<sha256>  LocalServerExposer_1.0.0_x64-setup.exe

A scheduled workflow re-checks the published checksums after every release and records the result in the Actions tab of the repository.

First launch

  • The window opens in about a second and immediately begins scanning.
  • A tray icon appears; closing the window keeps the app in the background.
  • The first time you expose a server, the app asks before downloading the cloudflared client. That download is explicit and never happens at install time.

Upgrade

Run the newer installer over the existing one. Settings, favorites and logs are preserved. To move back to an older build, uninstall first — the installer blocks downgrades by default.

Uninstall

  1. Use Windows

    Settings → Apps → Installed apps → Local Server Exposer → Uninstall, or the Uninstall shortcut in the Start Menu folder.

  2. What disappears

    The application, its shortcut and its uninstall entry. Any running tunnels stop.

  3. What stays

    Your settings, logs and the downloaded tunnel client in %APPDATA%\com.localexp.local-server-exposer\. Delete that folder for a complete removal.
