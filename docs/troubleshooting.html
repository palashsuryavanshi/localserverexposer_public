Troubleshooting and FAQ

Quick answers to the things people hit most often.

Discovery

No servers are listed

Check that your dev server is bound to 127.0.0.1 (some tools bind to a LAN address instead), then press Refresh. If you expected LAN addresses to appear, check Settings → Scan localhost only.

A port is marked Unsupported

It is listening but does not answer as HTTP or HTTPS — a database, a debugger protocol, a game server. This is deliberate: the app refuses to expose anything it cannot identify as a web server.

A port is marked Unreachable or Unknown

The socket was listed but did not answer the probe. That happens with firewalled ports, ports closing as you scan, or sockets owned by elevated processes whose identity the OS does not disclose to a normal user.

A server keeps disappearing and coming back

Short-lived processes (a dev server restarting, a test fixture) do that. Cards for servers that vanish while they are tunneled stay visible as unavailable so you can still stop the tunnel.

Tunnels

Expose is unavailable

Only cards marked Ready can be exposed. Anything else is either not an HTTP(S) service or was not reachable when it was scanned.

"cloudflared is not installed yet"

The tunnel client is downloaded on demand, never bundled. Open the Tunnels page and choose Install cloudflared (needs internet), or point Settings → cloudflared executable at an existing copy. The copy is checked before every tunnel starts, so a wrong or corrupted file is refused.

The tunnel stays on Starting

Cloudflare edge registration normally completes within a few seconds. If it has not after about a minute the app stops waiting and reports the failure. Usual causes: no internet connection, a captive portal, a proxy or VPN that blocks the connection, or Cloudflare being unreachable from your network.

The tunnel says Tunnel failed

Read the message on the card — it names the reason — then press Retry. Common ones: the network dropped mid-registration, the tunnel client was deleted or replaced while running, or Cloudflare rejected the connection.

My public URL stopped working

Check whether the tunnel still shows Exposed. If it stopped, start it again — each new tunnel gets a new URL; the previous one is not reused.

What happens to my tunnels if the app crashes or I sign out?

They are stopped. Tunnels are attached to a Windows Job Object, so the operating system terminates them when the app's process goes away. A public URL can never keep serving without the app that you can use to stop it.

The app

The window does not open, or opens blank

Install or repair the Microsoft Edge WebView2 Runtime, then restart the app. If it still fails, reinstall from the releases page.

Where did the window go?

Closing the window hides it to the tray when Minimize to tray is on (the default). Use the tray icon to reopen it, or turn the setting off.

Where are the logs?

Settings → Open logs folder opens %APPDATA%\com.localexp.local-server-exposer\logs\. Daily files are kept for 7 days; panic.log appears only if the app ever crashes.

Does it slow my machine down?

No. Idle CPU use is effectively zero and a scan costs a fraction of a percent of one core, even with dozens of listening ports. You can also lengthen the scan interval in Settings.

Installation and SmartScreen

"Windows protected your PC" / "unrecognized app"

Expected — the binaries are not code-signed, so they have no publisher reputation. Confirm you downloaded the file from the releases page, verify it against the published SHA256SUMS.txt, then choose More info → Run anyway. Never disable SmartScreen permanently.

The installer asks for administrator rights

It should not: the installer is per-user. If you are prompted, something in your environment is rewriting the install — check with your administrator.

Where is the app installed?

%LOCALAPPDATA%\Local Server Exposer. Settings, logs and the downloaded tunnel client live separately in %APPDATA%\com.localexp.local-server-exposer\.

Uninstalling left my data behind

Intentional. Settings, favorites, logs and the downloaded tunnel client are kept so a reinstall keeps your preferences. Delete that folder to remove everything.

Frequently asked questions

Does this need port forwarding or a router configuration?
No. Outbound connections only. Nothing on your router has to change, and you do not need a static IP.
Is there a usage limit or a tunnel duration limit?
The app imposes none. Tunnels last as long as they are running, and Quick Tunnels are intended for development use.
Can I use my own domain, or my Cloudflare account?
Not in this version. Only anonymous Quick Tunnels are supported.
Can it share a database, SSH, or an admin panel?
It will refuse. Exposure requires the target to answer as HTTP or HTTPS, checked again immediately before a tunnel starts.
Does it collect telemetry or analytics?
No. There is no telemetry, no crash reporting to third parties, and no network activity beyond the tunnel and the one-off tunnel-client download. See security and privacy.
Why isn't the source code available?
This project publishes compiled binaries and documentation. The application source is kept private.
How do I report a problem?
Open an issue on GitHub with the app version, your Windows version and what happened. Never paste a live tunnel URL — a URL is access to your server.
