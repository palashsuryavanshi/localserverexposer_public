Installation

Local Server Exposer is a per-user Windows application. Installation needs no administrator rights and does not change system-wide state.

Requirements

Operating systemWindows 10 or 11, 64-bit (x64)
DiskAbout 3 MB for the installer
Other softwareMicrosoft Edge WebView2 Runtime — normally already present; the installer offers to fetch it if missing
InternetNeeded to start a tunnel, and once to download the tunnel client (~55 MB)

ARM64 and non-Windows platforms are not supported.

Install the latest release

  1. Open the releases page and download LocalServerExposer_1.0.0_x64-setup.exe.
  2. Run the installer — it is a per-user install, so no administrator prompt appears.
  3. Launch Local Server Exposer from the Start Menu.

What the installer does:

  • installs the app under %LOCALAPPDATA%\Local Server Exposer;
  • adds a Start Menu shortcut;
  • registers an uninstall entry under Settings → Apps → Installed apps;
  • installs the Microsoft Visual C++ runtime the app needs;
  • offers to install the WebView2 runtime if it is missing.

Your settings, logs and the optional tunnel client live in a separate folder, %APPDATA%\com.localexp.local-server-exposer\, so uninstalling the application does not delete them.

Verify the download

Each release publishes a SHA256SUMS.txt. To check the installer in PowerShell: 

Get-FileHash ".\LocalServerExposer_1.0.0_x64-setup.exe" -Algorithm SHA256

Compare the result with the published value:

f9c5b14266ea4ca4f337bc07053c6e3a160ead384286a82e75ecbc01a00c12a4  LocalServerExposer_1.0.0_x64-setup.exe

The binaries are not code-signed, so Windows SmartScreen shows an "unrecognized app" warning on first run. Verify the checksum before choosing More info → Run anyway.

First launch

  • The window opens in about a second and starts scanning for local servers.
  • The tray icon appears; closing the window keeps the app in the background.
  • The first time you expose a server, the app asks before downloading the cloudflared client. That download is explicit and never happens at install time.

Upgrade

Run a newer installer over the existing one. Settings, favorites and logs are preserved. To move back to an older build, uninstall first — the installer blocks downgrades by default.

Uninstall

  1. Settings → Apps → Installed apps → Local Server Exposer → Uninstall, or the Uninstall shortcut in the Start Menu folder.
  2. The application, its shortcut and its uninstall entry are removed.
  3. Your data in %APPDATA%\com.localexp.local-server-exposer\ is kept — delete that folder manually for a complete removal.
  4. Any running tunnels are stopped when the application exits.
